Each of the sub-assignments are found in the Java files here in /src

1. ASCII_Decimal:
    Program will ask for a String, type out any String on the next line.
    It will then print out the ASCII values of each character on its own line.
    Program will call itself again.

2. Numberbase_Converter
    Program will ask you for the base of the number you want to input, type either: decimal, hex, binary,or octal.
    Program will then ask for the number itself, make sure to type in the base you selected or else it will print N/A.
    It will print out that number in the other 3 bases you didn't select.
    Program will call itself again.

3. Print_Pixels
    Program will ask which file you want to input, type in the image's name (case sensitive and with extension like ".png".
    image must be in the main folder.
    Program will output the "output.txt" file to main folder.

4. Pixels_to_Image
    Program will read the file "input.txt" in the main folder and print out the Characters from it while outputting "output.png".
